
参考 .vscode/launch.json 中的 extract 和 scale 任务，使用临时脚本重新生成一次全量数据。

生成之后的数据应该和 data 目录中现有的一些数据集结构类似，可能不是完全一致。

生成完成后，参考 docs/train 目录中过往的训练记录，使用新的数据集全量训练一次项目中的预测器模型。

使用多项指标评估预测器性能，并将数据集、训练结果、评估结果和详细分析记录到新的训练文档中，保存到 docs/train 目录下的 markdown 文件中。文档命名参考现有的日期命名方式，采用今天的日期。如果今天的日期已经存在一个训练文档，那就在日期后面加上一个后缀，例如 _v2。
