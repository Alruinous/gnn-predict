# GNN 预测器 20260531 清理归档

## 迁移结论

本次迁移只保留一个主线方案：单一多目标 GNN 预测器，使用规范化后的 v3 数据集。

这里的 WAPE 指加权绝对百分比误差。后文保留英文指标名，是因为训练代码和结果 JSON 中使用这些字段名。

保留方案：

- 配置：`config/gnn_model/scaled_training_v3_20260531.yaml`
- 数据：`data/scaled_v3`
- scaler：`data/scalers_v3`
- extracted：`data/extracted_v3`
- 目标：7 个目标共同训练
- 模型：`hidden_dim=128`、`num_layers=2`、`num_heads=8`
- 图读出：`mean_sum_max`
- 结构上下文：`structural_context_mode: basic`
- 训练权重：`[1, 1, 1, 1, 1, 2, 1]`
- 选择原因：在保留单一 GNN 预测器、不使用后处理堆叠、不使用单目标模型的约束下，test overall WAPE 最低。

## v4 profiler 路线结论

profiler micro-pass 与 top-event 特征有信号，但没有足够稳定地刷新主线 GNN：

- 96-row probe：tabular 和 GNN 均显示 profile 对部分目标有帮助，但样本太小。
- 216-row wide probe：tabular 五个硬件目标同向小幅改善，SM occupancy 只改善约 0.005。
- 216-row GNN：overall、memory、gpu util、gpu memory 改善，但 SM occupancy 和 SM active 退化。

因此 v4 profiler 相关数据和输出全部删除。后续如重新研究 profiler，应新开分支并重新定义任务为 profile-assisted predictor，而不是纯架构预测器。

## 后处理与堆叠路线结论

删除所有后处理路线，包括：

- family scale / family bias
- base_phase affine calibration
- residual stacker
- out-of-fold residual stacker
- device-aware specialized stacker
- repeated second-level out-of-fold ridge stack
- group switch / group blend
- target-specific checkpoint pool

原因：

- 它们不是单一 GNN predictor。
- 部分方法使用 validation residual 或 out-of-fold prediction pool，会增加部署复杂度和 test-coupling 风险。
- 指标即使更低，也不符合这次迁移的主线约束。
