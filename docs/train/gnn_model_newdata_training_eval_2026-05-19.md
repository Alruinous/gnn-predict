# GNN 预测器新推荐模型数据等权训练评估报告

## 执行摘要

本次基于当前 `data/scaled` 全量数据重新训练 `src/gnn_model` 的 GNN 性能预测器。
当前有效样本数为 `22,510`，相比 2026-05-13 报告的 `19,774` 增加 `2,736` 条。

本次按要求不修改各目标 loss 权重：

- 6 个预测目标保持不变。
- 临时训练配置未写入 `loss_weights`，即全部目标等权。
- 未使用 `cpu_w0p10`、`cpu_p0` 或其他 CPU 降权方案。
- 模型规模仍为 `hidden_dim=128, num_layers=2, num_heads=8`。

核心结果：

- 训练跑满 `100` epoch，best checkpoint 出现在 epoch `96`。
- best val loss 为 `0.077473`，last train loss 为 `0.084125`。
- test original-scale WAPE 为 `0.131380`，R2 为 `0.888367`。
- 本次补充报告 MSE：test normalized MSE 为 `0.366969`，test original-scale MSE 为 `476,781.968750`。
- 新增推荐模型数据显著抬高了显存误差尾部，test original-scale RMSE 从 2026-05-17 等权 run 的 `192.125535` 升到 `690.494019`。
- `deepfm`、`dcn`、`edcn` 是本轮最主要的退化来源，`dcnv2` 表现相对稳定。

## 判断

本次训练流程可信：

- 使用当前 `data/scaled` 全量数据，样本数为 `22,510`。
- 临时 YAML 未设置 `loss_weights`，训练为等权目标。
- 训练完整跑满 100 epoch。
- best checkpoint、result JSON、扩展指标均已落盘。
- result JSON 和扩展指标均包含 MSE。

本次模型效果不适合作为“新增推荐模型后性能改善”的结论：

- 等权训练在当前新增推荐模型数据上明显受显存尾部影响。
- `gpu_mem_used_mb_p95` original-scale MSE 达到 `2,860,482.750000`，是整体 MSE 最大来源。
- `deepfm`、`dcn`、`edcn` 的显存误差说明当前图特征或数据分布不足以稳定解释这些推荐模型族。
- `dcnv2` 表现相对稳定，说明并非所有推荐模型都会造成同等退化。

当前建议：

- 保留本次等权训练作为新增推荐模型数据后的 unweighted 基线。
- 不把本次等权模型作为当前最佳部署模型；若目标是业务预测效果，仍需和 `cpu_w0p10` 或更合理的目标权重方案对照。
- 下一轮应重点诊断推荐模型显存标签和图特征，尤其是 `deepfm`、`dcn`、`edcn` 的高显存样本。
- 更严格的下一步仍是按 `variant_name` group split 和 train-only scaler 重训，避免当前行级 split 的乐观偏差。
